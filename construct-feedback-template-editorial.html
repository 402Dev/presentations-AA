Feature 01 / Form

Anchor slot stability

A form-side feature about whether a construction keeps one stable anchor slot across related realizations.

Category: Form
Working definition
The construction preserves one privileged slot that stays stable enough to anchor recognition and indexing.
Example
"the X-er, the Y-er" keeps its comparative spine visible
The lexical fillers vary, but the comparative scaffold stays recognizable.
Why discuss it
For review purposes, this feature only needs to earn one claim: that it helps separate stable frame cues from looser paraphrase families.
What I want to know
  • Analytic gainDoes it change how you group related constructions?
  • BoundaryWould you still need it once lexical fixation is already described?
Feature 01 / Review lens

What we actually need to decide

Keep it if
  • ContrastIt makes a visible difference in how two close patterns are compared.
  • RetrievalIt gives you one cue you would actually search or annotate for.
  • Teaching valueIt helps explain why speakers still recognize the pattern across variation.
Main concern
The feature may collapse into general lexical fixation unless the anchor slot does real comparative work.
Reviewer prompt
“Does this feature let you see a contrast that would otherwise stay hidden?”
Feature 01 / Input
Discussion focus
Is anchor slot stability worth keeping as a feature?
Focus the judgment on usefulness for analysis and communication, not on final naming.
“Would this help you distinguish constructions in practice, or is it already implied elsewhere?”
Comments can capture alternative wording, missing evidence, or a boundary case to revisit.

Feature 02 / Meaning

Pragmatic pressure gradient

A meaning-side feature about how strongly the construction invites urgency, insistence, or social pressure.

Category: Meaning
Working definition
The construction encodes a graded expectation that the utterance should be taken as pressure-bearing rather than neutral.
Example
"You really ought to at least have told me."
The construction frames the proposition as carrying social pressure, not only content.
Why discuss it
This feature is only worth keeping if it names a stable meaning contrast rather than general discourse coloring.
What I want to know
  • StabilityDoes the pressure component stay visible across multiple examples?
  • OverlapWhere does this stop and a speech-act or stance label begin?
Feature 02 / Review lens

What would justify keeping it

Keep it if
  • Meaning contrastIt explains why close paraphrases still differ in felt force.
  • Comparative gainIt lets you compare sibling constructions more clearly.
  • RepeatabilityYou can point to stable examples rather than one-off contextual effects.
Main concern
If the definition keeps absorbing stance, modality, and speech-act language at once, the feature is too broad to survive.
Reviewer prompt
“Do you see stable pragmatic pressure here, or only context-specific interpretation?”
Feature 02 / Input
Discussion focus
Is pragmatic pressure gradient worth keeping as a feature?
Treat this as a question about analytical usefulness and definitional discipline.
“Would this feature produce repeatable judgments, or does it remain too dependent on context?”
Use the note field for one counterexample or one better label if you have it.
