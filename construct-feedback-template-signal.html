Feature 01 / Relational

Argument linking transparency

A relational feature that measures how directly the construction exposes the mapping between participant roles and overt morphosyntactic positions.

Category: Relational
Working definition
The construction reveals participant-role assignment with minimal inference, making the relational mapping inspectable from the overt pattern itself.
Quick example
"X gave Y Z" surfaces giver, recipient, and transferred entity directly.
The mapping is legible without extra structural reconstruction.
Why it might deserve a slot
If it survives review, this feature gives you a compact way to compare constructions that distribute the same roles with different degrees of overtness.
What I want to know
  • SignalIs mapping visibility a contrast you actually use when comparing alternations?
  • Overlap riskDoes the feature add anything beyond ordinary syntax description?
  • Decision testIf it never changes the comparison, it should probably stay out.
Feature 01 / Decision lens

Keep it only if the contrast is real

Keep it if
  • ComparisonIt sharpens a relational contrast you would otherwise describe too loosely.
  • CompressionIt lets you summarize an alternation difference without re-explaining the whole pattern.
  • ReuseYou can imagine annotating or querying for it more than once.
Main risk
The label becomes decorative if it simply renames transparent syntax without adding analytic leverage.
Reviewer prompt
“Does this label sharpen a comparison you actually make, or only describe something already obvious?”
Feature 01 / Input
Decision prompt
Should argument linking transparency remain in the feature set?
Judge the feature by whether it materially improves relational comparison across constructions.
“Would you use this label when comparing alternations, or would you ignore it in real analysis?”
Use the comment for one alternation, counterexample, or narrower reformulation.

Feature 02 / Meaning

Contextual contrast window

A meaning-side feature that identifies how much surrounding contrast is required for the construction's intended interpretation to become stable and recoverable.

Category: Meaning
Working definition
The construction depends on a bounded amount of contextual contrast before its intended interpretation resolves consistently for speakers and analysts.
Quick example
Short fragments that only read ironically once a contrastive frame is established.
The construction needs a small window of discourse contrast to settle its meaning.
Why it might deserve a slot
If retained, the feature gives you a compact way to talk about context dependence without drifting back into general commentary.
What I want to know
  • ThresholdCan the contrast window be bounded rather than vaguely implied?
  • ReuseWould this help compare more than one construction?
  • Decision testIf it stays fuzzy, it is probably better as a note than as a feature.
Feature 02 / Decision lens

Keep it only if the threshold holds

Keep it if
  • InterpretationIt explains why the same form stabilizes only once contrastive context is present.
  • ComparisonIt gives you a bounded way to compare context-sensitive constructions.
  • DisciplineYou can imagine annotating it without relying on private intuition.
Main risk
The feature becomes too broad if it simply restates that interpretation is context-sensitive.
Reviewer prompt
“Can you imagine annotating this consistently, or would the judgment stay too intuitive?”
Feature 02 / Input
Decision prompt
Should contextual contrast window remain in the feature set?
Judge the feature by whether it gives you a bounded, reusable way to discuss contextual dependence.
“Is this a disciplined feature, or just a good observation that belongs in the notes?”
Use the note for one threshold idea, missing example, or counterexample.
