# presentations-AA

A small collection of Construction Grammar (CxG) presentations built as self-contained HTML decks.

## Presentations

| # | File | Description |
|---|------|-------------|
| 01 | `constructicon-feature-review.html` | Interactive feature review — 73 slides, 23 feature blocks across 5 families (Form, Meaning, Relational, Meta, Acquisitional). Records judgments and shows decision summaries. |
| 02 | `cxg-basics.html` | Construction Grammar anatomy deck — 79 slides covering the full feature inventory from Form to Acquisitional structure. |
| 03 | `con-in-action.html` | Compact worked example — 4 slides walking through a single construction entry ("What's X doing Y?"). Good for live demos and teaching intros. |
